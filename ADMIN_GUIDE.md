# HireFlow Administrator Guide

## Overview

This guide covers administrative tasks for HireFlow organization administrators.

---

## Organization Management

### Creating an Organization

1. Navigate to Team Dashboard
2. Click "Create Organization"
3. Enter organization name and URL slug
4. You become the Owner

### Managing Members

#### Inviting Members
1. Go to Team → Invite
2. Enter email address
3. Select role (Admin, Recruiter, Hiring Manager, etc.)
4. Send invitation

#### Roles & Permissions

| Role | Permissions |
|------|-------------|
| **Owner** | Full access, manage organization |
| **Admin** | Most access, cannot delete org |
| **Recruiter** | Manage candidates, jobs, pipeline |
| **Hiring Manager** | Review candidates, interview feedback |
| **Interviewer** | Interviews, scorecards |
| **Viewer** | Read-only access |

#### Removing Members
1. Go to Team settings
2. Find the member
3. Click "Remove"
4. Confirm removal

### Organization Settings

Admins can configure:
- Organization profile
- Brand colors and logo
- Email templates
- Security policies
- API keys
- Webhooks

## Billing Management

### Viewing Plans
1. Navigate to Billing settings
2. View current plan and usage
3. Compare available plans

### Changing Plans
1. Select desired plan
2. Review pricing
3. Confirm upgrade/downgrade
4. Prorated billing applies

### Managing Invoices
1. Go to Billing → Invoices
2. View payment history
3. Download invoices

---

## User Management

### Adding Users
- Invite via email with role assignment
- Users accept invitation via email link
- Role determines access level

### Changing Roles
1. Go to Team → Members
2. Find the member
3. Click "Change Role"
4. Select new role
5. Confirm change

### Deactivating Users
1. Go to Team → Members
2. Find the member
3. Click "Deactivate"
4. User loses access immediately

---

## Security Settings

### API Keys
1. Go to Settings → API Keys
2. Click "Create API Key"
3. Select scope (read, write, admin)
4. Copy key securely
5. Keys shown once — save immediately

### Webhooks
1. Go to Settings → Webhooks
2. Add webhook URL
3. Select events to receive
4. Save webhook secret

### Security Best Practices
- Enable MFA for all admin accounts
- Rotate API keys quarterly
- Review member access monthly
- Monitor audit logs
- Use strong, unique passwords

## Troubleshooting

### Common Issues

**Cannot invite members:**
- Check your role (must be Admin or Owner)
- Verify email address
- Check organization limits

**Cannot access features:**
- Verify your role permissions
- Check organization membership
- Contact admin if needed

**Billing issues:**
- Check payment method in Stripe
- Verify subscription status
- Contact support if needed
