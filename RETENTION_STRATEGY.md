## Retention Levers

### 1. Activation (Day 0-1)
**Goal:** Get users to value within first session

**Job Seeker Activation:**
- Create first application within 5 minutes
- See AI insights on first application
- Connect email for auto-import

**Employer Activation:**
- Create first candidate within 5 minutes
- Send first response to candidate
- Invite one team member

### 2. Engagement (Day 2-7)
**Goal:** Establish daily usage habit

**Engagement Triggers:**
- Application status changes
- New job matches
- Interview reminders
- AI daily brief
- Team notifications

**Engagement Loops:**
- Save job → Apply → Track → Get insights
- Receive application → Review → Respond → Track

### 3. Value Demonstration (Day 7-30)
**Goal:** Show measurable impact

**Value Metrics:**
- Applications tracked
- Time saved vs manual
- AI insights generated
- Interviews scheduled
- Team collaborations

**Value Communication:**
- Weekly email summaries
- Monthly progress reports
- ROI calculations

### 4. Expansion (Day 30+)
**Goal:** Increase feature usage and plan value

**Expansion Triggers:**
- Approaching plan limits
- Team growth needs
- Advanced feature requests
- Integration needs

## Churn Prevention

### Early Warning Signs
- No login for 7 days
- No application created for 14 days
- No AI features used
- Failed payment
- Negative feedback

### Intervention Strategy
| Signal | Action | Timing |
|--------|--------|--------|
| 7-day inactivity | Email: "Tips to improve your search" | Day 7 |
| 14-day inactivity | Email: "We've made improvements" | Day 14 |
| Failed payment | Email: "Update payment method" | Day 1 |
| Downgrade | Email: "We'd love to understand why" | Day 1 |
| Support ticket | Personal follow-up | Within 24 hours |

### Win-Back Campaigns
- **30 days inactive:** "Come back to HireFlow" email
- **60 days inactive:** Special offer email
- **90 days inactive:** "We've added new features" email
